# Web 管理项目 Agent 任务

## 目标与使用流程

面向已获授权的项目操作者，不再只有实例/会话看板。沿用 **Iris + Svelte 5 + Bun**、
官方 Snaplink SDK 和既有 Hub/Gateway，不引入第二套任务、身份或执行内核。

网页的“任务会话”就是 Hub AgentSession，“指令”就是 Turn；不是独立的 Task Center
目标验收记录。一个会话串行处理轮次。入口为工作台的 **管理 Agent 任务** 或侧栏 **Agent 任务**。

1. 使用 Snaplink 登录，进入任务页，读取本人权限及授权实例/会话窗口。
2. 点击 **新建任务**，选择目标实例和固定项目，输入名称，点击 **创建任务**。
   `queued` 只表示受理；创建期间预留容量，没有自动执行 prompt。
3. 页面持续查询原创建请求。Gateway 返回 `created` 后，自动进入对应任务。
4. 输入目标、范围及验收要求，点击 **发送指令**；Hub 持久化幂等轮次，原 Gateway 执行。
5. 在 **对话** 中持续查看当前轮次输入、回复、执行状态及命令/文件变更摘要。
   `message.completed` 替换同一消息的增量文本，分块按顺序合并；缺片/截断明确显示。
   回复支持有界的标题、段落、引用、列表及代码围栏预览，可切换原文或精确复制代码/回复；
   HTML、图片、链接保持文本，不加载外部内容。**轮次记录** 可分页打开历史输入与回复，
   **执行事件** 保留原始诊断证据。
   **轮次记录** 支持按可见指令或轮次 ID 搜索、按状态筛选及前后翻页；打开历史轮次后，
   地址中的精确轮次链接可收藏，也可点击 **复制本轮链接**。链接只含会话/轮次 ID，打开时重新鉴权。
   执行完成或失败后，可在同一任务中显式发送下一条指令，不自动执行后续步骤。
6. 需要停止时，勾选确认再 **请求取消活动轮次**。`cancel_requested` 不是已停止，
   以 Gateway 终态为准；可能与自然完成竞争。空闲会话可请求关闭，确认 `closed` 后才释放容量。
7. 打开 **结果检查**，核对当前轮次的命令退出码、报告的变更路径、验证/门禁记录和产物元数据。
   可下载当前已读取的轮次 JSON 记录或可读文本报告；下载不触发执行、额外读取或自动分页。
   执行网关显式开启命令输出共享后，可展开命令的终态输出、复制当前显示内容，或随轮次记录下载。
   显式启用文件检查后，可刷新执行端允许的文件快照，核对摘要、预览文本及下载原始字节。

任务列表支持按名称、项目或会话ID搜索、按实例及状态筛选，并翻页读取授权任务。
搜索提交后由服务端查询，不限于首100条；每页最多20条，翻页替换当前列表，
不无限累加。`#tasks/{session_id}` 可收藏或刷新恢复任务，
恢复时重新鉴权，不自动提交指令。现场刷新、轮次切换和站内导航保留按账号上下文/会话隔离的
有界内存草稿；退出、撤权、换账号及 pagehide 清除。整页离开前提示未发送草稿，浏览器不持久存储正文。
输入框支持 Ctrl/⌘+Enter，运行中也可先起草下一条；发送仍等待串行轮次空闲。

### 跟随任务现场与固定查看一轮

- 任务级链接 `#tasks/{session_id}` 显示 **跟随任务现场**。刷新与自动同步优先读取当前活动轮次，
  没有活动时读取未筛选的最新轮次；同一任务由其他浏览器或 CLI 发起新一轮后，也能跟进。
  轮次变化会替换正文和事件窗口，不把不同轮次的回复混在一起，也不逐次增加浏览器历史记录。
- 从 **轮次记录** 打开一轮，或访问精确轮次链接，显示 **固定查看此轮**。
  固定的可以是正在运行的当前轮次，也可以是较早轮次；同步只更新这一轮，不被别的轮次抢走。
  任务现场另有轮次时，显示它的 ID 和已读取状态；排队或运行中不表示已有结果。
- 点击 **回到任务现场** 恢复跟随，保留同会话的未发送草稿、历史搜索条件和分页位置。
  历史筛选、较早页和空搜索结果都不会改变现场的选择。此操作只读取，不提交指令。
- 固定查看时发送新指令，仍是在当前会话中继续执行，不会回滚、分支或重放历史；
  受理后回到任务级跟随。未知提交始终保留原目标、正文和 key，导航不替代请求核对。
- 精确链接指向不存在或无权访问的轮次时，不回退到最新内容冒充原目标。
  前进、后退和整页刷新按链接重新核对模式和授权；自动跟随不扩大授权，也不延长读取预算。

### 复用已读取的指令

需要沿用过去的目标或验收要求时，先从 **轮次记录** 或 **多轮回顾** 打开对应轮次，
再在 **对话** 中点击指令下方的 **复用本轮指令**。核对来源并编辑 **复用指令预览**，
点击 **加入当前草稿**，继续在原编辑框整理，再使用原 **发送指令** 按钮提交。

- 来源仅是当前已打开轮次的已读取、脱敏和显示规范化后的指令，不是最初提交原文的备份。
  脱敏标记照实保留，不恢复秘密；记录已截断、为空或无效时拒绝复用，不拿列表摘要补全文。
- 空草稿直接载入；已有草稿保留点击当时的完整内容，再追加编辑后的指令。
  预览期间继续编辑原稿不会丢失；同一预览成功加入后即消费，连续点击不重复追加。
  追加超过 65536 UTF-8 字节时保留原稿与预览，不截断。单次发送仍限 16384 字节。
- 打开预览时暂停对话自动跟随，新回复不会抢走编辑位置；可用原 **跟随最新输出** 按钮恢复。
  放弃预览或加入草稿不会自动恢复跟随。
- 普通刷新期间暂时禁用加入操作，仍可继续编辑预览并保持焦点；切换轮次、任务、身份或实例，
  来源变化、读取失效、撤权、隐藏或离开页面会清除预览。加入时重新核对实际页面目标与草稿上下文。
- 运行中或实例离线时仍可整理已读取的指令；只读、关闭会话及存在未决提交时不能复用。
  未知请求的原目标、正文和幂等 key 保持不变，不能通过复用绕过核对。

预览与追加只改本页内存中的草稿，不额外读取历史、不发送请求，也不自动重放过去的任务。
历史指令不授予额外执行权限，发送前仍需核对当前目标、修改范围和验收要求。

### 在长对话中查找和定位

在 **对话** 页输入 **查找本轮对话** 并提交，可以定位当前已显示指令与 Agent 回复中的文字。
使用上一处、下一处检查匹配位置；定位后暂停自动跟随，新的输出不会把你正在阅读的位置推到底部。

- 查找按字面匹配，不把输入解释为正则表达式；大小写使用 Unicode 简单折叠，中文和代码均可查找。
  条件最多 128 个字符 / 512 个 UTF-8 字节，控制或 bidi 字符无效。空条件清除查找。
- 只查找当前指令和既有回复投影（最多 64 条 / 256 KiB），不查草稿、命令输出或其他轮次，
  不请求后续事件、自动翻页或读取工作区。未找到只表示当前显示范围没有匹配，不证明未读部分不存在。
- 最多定位前 200 处匹配，达到上限时明确提示。回复跨事件分块先按现有规则组成正文，再参与查找；
  不跨消息拼接匹配，也不扩大事件窗口或回复预算。
- 匹配回复以原文显示并标记匹配位置，文字不会成为 HTML 或可执行内容；清除后恢复原有显示偏好。
  已超出格式预览预算的回复继续显示原文，不因查找放宽预览预算。
  查找与定位不修改草稿、未知提交或任何任务执行状态。清除查找后仍暂停跟随，可显式恢复 **跟随最新输出**。
- 同一轮次刷新保留条件，但依据最新已读正文重新核对位置；正文替换或片段被移出窗口后，不沿用失效位置。
  换任务、换轮次、身份变化、失去读取权限、隐藏或离开页面后清除。条件不放入链接、浏览器存储或导出文件。

对话页、多轮回顾和结果检查共用回复结束记录判断。终态轮次仍有已读回复缺少结束标记时，
显示完整性未知；收到结束标记也不代表中间片段齐全。运行中的正常增量回复不因此标成失败，
回顾中各轮按自己的状态判断。执行完成与独立目标验收仍然分开。

### 对照多轮指令与回复

同一任务经过澄清、实现和修复后，可以打开 **多轮回顾**，一起对照最近五轮的指令与回复。
本页按从早到晚排列，轮次各自显示 ID、执行状态和创建时间；同名消息或没有消息标识的旧记录
只在所属轮次内合并，不把多个轮次拼成一段回复。执行状态仍不代表独立目标验收。

- **更早的五轮**、**返回较新一页** 按页替换内容；**最新五轮** 回到最近记录，
  **刷新本页回顾** 重新读取当前页。最多保留 32 个返回位置，不累加所有历史正文。
- 回顾是显式读取的快照，显示读取时间。新的活动轮次及普通现场同步不会抢走回顾页；
  各轮记录可能在不同时间读取，不能视为整个会话的一致时间点快照。
- 点击某轮的 **打开此轮** 进入原有固定查看模式，再使用结果检查、文件检查或引用起草。
  回顾分页不改变当前选择、历史搜索和同会话草稿，也不自动把历史正文追加为新指令。
- 每轮最多读取前 100 条事件，整个回顾窗口最多保留 500 条/1MiB 事件数据，五轮均分字节额度。
  尚有后续、较早片段未保留、缺片和截断分别标明；未读到回复不能推断该轮没有回复。
  需要更多内容时打开对应轮次，使用原有 **读取后续事件**。
- 所有读取复用原有前后鉴权及 12 秒整体窗口。切换任务、离开任务工作区、撤权、身份变化或
  pagehide 清除回顾并取消自有读取，迟到内容不能进入另一个任务；重新进入后显式读取。
  只读任务授权也能回顾。未知提交的原目标、正文和 key 保持不变，回顾不能代替原请求核对。

这项功能不提供回复全文搜索、自动摘要、历史重放或额外执行权限；草稿仍由用户编辑并显式发送。

### 保存草稿并在稍后继续

在指令编辑框下展开 **草稿文件**，点击 **保存草稿文本**，将当前编辑框的完整原文保存为 `.txt`。
这适用于离开页面前保留已经整理的目标、范围和后续指令。文件可能包含用户写入的敏感内容；
备份不额外加入登录上下文、凭据、待提交请求或幂等 key，也不证明其中的指令尚未执行。

1. 回到已授权的任务，展开 **草稿文件**，选择本地 UTF-8 `.txt` 文件。
2. 在 **导入草稿预览** 中核对原文和当前目标。文件只在本页读取，不上传；HTML、URL 和
   JSON 形状的文本都不解释为页面、远程资源或恢复协议。
3. 点击 **加入当前草稿**。空编辑框直接载入；已有内容时追加到点击当时的最新原稿，
   预览期间的新编辑也会保留。成功后回到编辑框，同一预览不能因双击重复加入。
4. 继续编辑并核对内容，再使用原 **发送指令** 或 Ctrl/⌘+Enter；备份、读取和加入都不发送请求。

- 草稿保持既有每会话 65536 UTF-8 字节、最多 16 个会话的内存预算；文件也最多 65536 字节。
  输入框支持编辑此范围的文本，单次发送仍硬限 16384 字节。较大草稿可以保存、恢复和精简，
  不能直接发送；追加超限时保留原稿和预览，不截断、不覆盖。
- 读取前检查文件大小，读取后复核实际字节数；最多 128 块、整个读取最多 5 秒，持续进度不续期。
  坏 UTF-8、空白文本、控制或 bidi 字符会被拒绝；允许 tab/LF/CR，保留 BOM 与原始换行。
  这是草稿文件入口的规则，不修改已有 prompt API 或静默清洗原文。
- 普通后台刷新暂时禁用文件操作，但不会清掉同一任务的预览。切换任务、退出、撤权、事实失效
  或 pagehide 会取消自己的读取并清除预览；迟到数据不能进入另一个任务的草稿。
  文件没有授权效力，加入时由原草稿 owner 同步复核当前登录上下文、实例、会话及实际页面目标。
- 已有未知提交仍按原目标、正文和 key 核对，期间禁止文件操作，不能导入后绕过核对重发。
  实例离线或当前轮次运行中仍可整理本地草稿；关闭会话只能备份已有文本，不能导入或发送。
- 浏览器仍不持久保存草稿。整页刷新后，需要用户自己选择备份文件，不能自动恢复执行或授权状态；
  取消导入、读取失败及校验拒绝都保留原编辑框内容。

### 查找任务与处理失败

- 列表分别显示会话可用性与**最近执行**结局。轮次失败后会话可以仍为空闲，
  但该任务会进入**需处理**；取消、中断、失联也属于需处理。再次显式执行成功后，
  最近结局更新为已完成。这里的完成仅指执行终态，不是独立目标验收。
- 分类优先展示进行中的任务；已关闭会话单列。没有活动且最近失败的任务不会因
  会话恢复空闲而消失。离线和冻结仍按连接/控制状态表述，不伪造执行失败。
- 搜索支持Unicode大小写折叠，`%`、`_`按普通字符处理。搜索框未提交的文字
  不触发网络请求；后台更新不会覆盖正在输入的搜索文字。
- 翻页或切换筛选保留正在查看的任务、轮次及草稿；当前任务不在列表时可点击
  **定位当前任务**。浏览器只保留最近32页的返回游标，**首页**始终可回到起点。
- 每次分页重新核对授权，游标绑定身份、授权实例范围及查询条件。账号或授权变化
  清除旧结果、查询、选择和草稿；过期/无效分页不会反复卡在旧游标，手动刷新从首页重读。
  不存在的任务或轮次链接清除当前选择，仍可从列表打开有效任务；未知提交的核对信息不因此丢弃或重放。
  列表是当前事实窗口，执行状态变化可能使任务离开筛选结果，不是冻结的全量清单。

### 查找历史指令与精确轮次链接

- 在 **轮次记录** 输入查询词并选择 **轮次状态**，点击 **搜索轮次** 或在搜索框按 Enter。
  输入期间不请求；搜索范围是当前已授权任务，匹配轮次 ID 和接口返回的脱敏、有界指令文本，
  不匹配被遮蔽的秘密值。Unicode 使用 casefold，`%`、`_` 是普通字符，不是通配符。
- 每页最多 20 条，顺序为创建时间/轮次 ID 降序；可返回上一页、轮次首页，或用 **最新轮次**
  清除筛选。浏览器最多保留 32 个返回位置，不能据此推断完整历史数量。
  搜索/较早页保留到下一次手动查询，界面单独显示读取时间；已选轮次的状态和事件仍持续更新。
  查询或分页被拒绝时不显示空成功，失效条件重置后可用 **刷新任务现场** 恢复，再缩小范围。
- `#tasks/{session_id}` 保持任务入口兼容；`#tasks/{session_id}/turns/{turn_id}` 精确打开指定轮次，
  即使它不在当前历史页也读取完整的授权指令记录。缺失、跨会话或坏响应不能回退为最新轮次。
  刷新、前进/后退和站内导航保留精确选择；接受新指令后转到新执行轮次。链接不包含搜索词、正文或凭据。
- 导航请求到达时立即关闭旧详情及其文件读取，哪怕原任务刷新仍未完成；待提交写入仍保留
  原目标及幂等账本，导航不取消或重放它。草稿按原会话隔离，查询或换轮次不会发送草稿。
- 搜索词最多 128 字符/512 UTF-8 字节，拒绝控制及 bidi 字符。完整查询窗口最多 5 秒、
  100 万 SQLite VM 步；文本搜索最多扫描 5000 个候选/8MiB 指令字节，达到预算返回 503，
  不把已扫描部分伪装成完整结果。可缩小状态/文本条件；已有精确链接按 ID 定位，不扫描全文。
- 新分页游标绑定租户、会话、用户/client、实例授权集合和规范化筛选。旧 v1 游标仅在当前
  授权已核对、无搜索/状态筛选时兼容；它不是授权凭据。Web 和 Bearer 查询都拒绝坏 UTF-8。

运行会修改固定项目、调用 provider 或产生其它由 Agent 原授权允许的副作用。网页没有
任意文件浏览、cwd/provider切换、机器注册、发布/合并/部署按钮。取消、关闭、退出网页
都不代表代码或外部副作用回滚。Agent 成功不等于目标达成；费用、独立验收和审计仍未追踪。

### 结果检查与记录下载

- 命令输出默认不向Hub发布。执行网关可显式使用 `--publish-command-output`，
  向已有精确会话读取权限的用户分享经过脱敏的终态文本快照；网页不能自行开启。
  Codex的聚合输出事件和Appserver的命令结束输出受支持，逐片delta不转发。
  每个输出最多8KiB，遇到事件总预算还会进一步收紧；界面总输出显示最多256KiB。
  未提供、空文本、截断/省略分别显示。快照替换同命令的旧输出，不制造执行完成或退出码0。
  只显示执行端已经提供的文本，不读取产物路径、自动取完整日志或证明输出内容可信。
- 命令/验证按同轮次内消息标识合并开始与结束；没有标识的历史事件保持独立。
  退出码缺失显示未知，退出码0不等于验证或门禁通过；轮次已终止但活动缺结束记录时标明缺失。
- 只有结构化 `validation.started/completed`、`gate.verdict`、`artifact.created` 才进入相应记录。
  回复中的PASS不作证据；不一致的验证结论/退出码、无效状态或不完整元数据不升级为通过。
  普通Pi/Codex/Legacy会话未发出验证、门禁事件时显示未提供，不自动运行流水线或检查项目。
- 产物事件仅显示执行端提供的名称、路径、摘要、大小和类型，不驱动文件读取或证明内容有效。
  Gateway从`AgentSession.prompt_events`取得精确workspace/session/run/turn事件；旧轮次、未知run
  或其它工作区/会话事件不会落到当前Hub轮次。流队列最多256条/1MiB，采用背压而不丢弃有效事件。
  停止读取不释放执行所有权，也不重放任务。执行器返回无效身份时失败关闭并清理本会话拥有的runtime；
  清理失败单独报告执行结果未知，不声称进程已停止或项目改动已回滚。
- JSON schema为`abr.turn-record.v1`，包含当前会话/轮次、已读取回复和事件、观察时间/游标、
  截断、尚有后续事件及活动缺结束记录等完整性标记。目标验收始终单列为未独立验证。
  命令输出使用可选 `output_text` / `output_truncated` 字段，覆盖信息另标记 `command_output_partial`。
  `command_output_display_limited`只表示界面显示预算，不会把完整的已读导出内容误报为缺失。
  不额外加入登录上下文、凭据、幂等key、待提交内容或其它草稿；已显示的任务内容仍属于导出内容。
  下载最多2MiB，超限拒绝而非裁剪成完整记录；刷新未完成、读取已暂停或失去授权时不可下载。
- 轮次已经终止但某条回复没有结束标记时，完整性仍未知；结果检查及下载会标明
  `reply_completion_missing`。这不等于确定丢失了正文，也不能用轮次完成状态补造回复结束记录。
- 格式预览是有限块格式，不是完整CommonMark；不支持的语法保持原文。预览最多64KiB、1024行、
  256块及512个块/列表项，超出时展示完整的当前原文；仍受原有对话窗口预算限制。
  详情页签支持左右方向键、Home/End，桌面与手机共用相同选择和授权状态。

### 下载可直接阅读的本轮报告

在 **结果检查** 点击 **下载本轮可读报告**，保存 UTF-8 `.txt` 文件，便于离线阅读和交接。
原 **下载当前轮次记录** 继续提供 JSON；两种格式共用同一轮次、授权检查和字段白名单。

- 报告列出任务和轮次身份、执行状态、观察时间、已读取的指令与回复，以及执行端报告的
  命令、验证、门禁、文件路径、产物元数据和异常事件。每条事件保留 ID、游标及类型，便于核对来源。
- 正文是纯文本，不把 Agent 提供的 HTML、图片、链接或“通过”解释成页面、外部读取或验收。
  不可信内容与报告说明分开显示；报告不会自动总结、评价或改写执行结果。
- 仅导出当前已读取窗口，不读取后续页、日志、工作区或文件快照。页面前 64 条展示及命令输出
  显示预算不裁掉已读取事件；回复摘要使用既有有界投影，并附当前已读的原始回复片段，
  缺片、截断和投影遗漏会明确标注。
  缺少输出、空输出和截断输出分别说明；没有记录不证明没有发生相应活动。
- 进行中或只读授权的轮次也可以导出，状态与读取时间照实记录。目标验收始终为未独立验证，
  命令退出 0、回复中的 PASS、路径和摘要均不代表文件或目标已经验收。
- 每个文件仍最多 2MiB，按最终 UTF-8 字节检查，超限拒绝，不静默删减。草稿、未知提交正文、
  幂等 key 和登录上下文不加入报告；未知提交仍须按原请求核对，不因下载而重试或清除。
- 点击时重新核对当前任务视图、路由、登录上下文及精确会话/轮次；切换过程中旧按钮不能下载
  另一目标的数据。刷新中、同步暂停、撤权或离开页面后不可导出；下载本身不发起网络请求。

页面顶部的 **最近一次请求回执** 单独显示对应请求的类型、原目标及响应当时状态。
例如发送指令的回执可以仍为排队中，而该轮次随后已执行完成；当前执行状态以轮次详情为准。
切换任务不会把旧回执改写成新任务的状态，回执也不证明目标验收或取消后的副作用已回滚。

### 从结果记录继续处理

结果页顶部的 **结果记录工作区** 面向需要定位失败、核对未知结果并继续处理任务的用户。
它复用当前轮次的结构化事件投影；原来的执行状态、目标验收和发送门禁保持独立。

- 默认展示 **需要核对** 的记录，可切换全部、报告异常、结果未知、执行中、报告成功或已记录元数据。
  输入命令、原因、共享输出、路径或记录 ID，点击 **搜索结果记录** 或按 Enter 才应用条件。
  搜索是本页已读取数据的字面量匹配，不发起请求，也不扫描工作区或自动获取更多日志。
  每页 20 条，前后翻页可检查原分类列表前 64 条之外的已读取记录。
- 搜索仍受 500 条/1MiB 事件窗口限制，另可显示一条来自当前轮次状态的缺诊断提示。
  记录总数与异常数量只描述此窗口，零条异常不等于目标验收；继续读取可能改变结果。
  缺退出码、矛盾状态、缺结束记录保留未知；不完整的正向记录不会作为完整成功展示。
  命令退出 0 仍不是验证或门禁通过，回复正文中的 PASS 不进入验证记录。
- 点击记录查看组成记录的实际事件 ID、游标、类型，以及组合展示的退出码、原因、路径和共享输出。
  开始、结束和输出可能来自不同事件；不会把组合字段归属于最后一条输出事件。
  **起草后续指令** 生成最多 8KiB 的可编辑新增段落，保留会话、轮次和事件引用，并标明片段截断。
  引用将组合字段与真实事件分开；来源名单过长时标明省略，未提供输出与空文本分别表示。
  没有诊断事件时只引用轮次状态，不制造事件 ID 或原因；目标、范围与验收要求由用户补充。
- **追加到当前草稿** 保留点击当时的完整原稿，追加后回到对话并聚焦输入框。
  预览期间修改原稿也会保留；总内容超过 16384 UTF-8 字节时拒绝追加，两份草稿都不截断。
  一份预览成功追加后即消费，连续点击不重复追加。起草和追加均不发送请求；最终仍由原 **发送指令** 执行。
- 引用在内存中绑定登录上下文、会话、实例、轮次和实际记录字段。
  同内容轮询不清除正在编辑的预览；依据变化、记录离开窗口、撤权、切换或离开页面使引用失效。
  追加时由草稿 owner 再次同步校验；未知提交、读取未稳定、无写权限或关闭会话不能追加。
  未知请求的原目标、正文与幂等 key 不受影响，不能用引用绕过核对或重放请求。

这不是自动修复、目标确认或新执行入口。引用中的命令、路径和文字是待核对的报告，
不授予额外工具或文件权限；用户仍需检查新增段落后决定发送内容。

### 文件检查快照（显式启用）

文件检查用于执行结束后核对固定工作区的实际内容。它不是已验收交付物，也不证明文件由
本轮生成；各文件可能在不同时间采集，不能当作整个工作区的一致时间点备份。

启用需要三项独立配置：Hub 的 `web.file_snapshots: true`（同时要求 `web.control: true`）；
批准的 Web client、签名 token 与精确用户/实例 grant 均包含 `agent.artifacts:read`
及原有 `agent.sessions:read`；Gateway 启动时重复声明 `--share-file`，例如：

```bash
# 在已配置身份、TLS、固定 cwd 的原 gateway 命令后追加精确相对路径：
--share-file reports/result.json --share-file src/example.py
```

三者默认都不扩大。旧 control 配置及租户元数据读取策略不会获得文件内容权限。
新增配置不会授予权限；修改 grant 或 issuer client 仍需运营者按实际授权完成。
不要把密钥或私有配置放入共享列表。路径只由执行机操作者声明，模型回复、文件变更事件、
网页参数和文件名链接都不能增加共享路径。

- 成功轮次在释放会话所有权前采集；失败、取消和缺终态不读取文件，并尽可能记录不可用原因。
  只有 Hub 确认原终态事件后才上传。快照采集/上传失败不改写执行结果，也不重跑 Agent。
- 最多 8 个精确相对路径；每文件 64KiB、总内容 256KiB、请求 512KiB。
  固定工作区根身份，拒绝路径穿越、符号链接、硬链接、特殊文件、读取期间变化及已知敏感路径。
  已识别凭据使整个文件被拒绝，不篡改原字节后沿用旧摘要；这不是“文件绝无秘密”的证明。
  采集运行在自有子进程中，整个窗口最多 5 秒，可随 Gateway 停止取消。
- 已采集字节先持久化为不可变待发送内容；网络响应未知只重发原 ID 与原字节，不重新读工作区。
  Gateway 队列最多 16 份/8MiB、4096 条收据；Hub 每实例最多 16MiB/1024 文件，
  全局最多 64MiB/4096 文件/4096 集合。满额明确拒绝，不静默淘汰。此版本没有网页清理按钮。
- 点击 **刷新文件快照** 获取列表，点击 **检查 文件名** 或 **下载 文件名** 才读取内容。
  每次读取重新鉴权；网页核对目标绑定、字节数和 SHA-256，失败则拒绝预览和下载。
  文本以纯文本展示，二进制不渲染；下载保留原字节，空文件与缺失文件分别显示。
  切换任务、轮次、账号、权限或离开页面会中止请求、清空预览并撤销临时下载 URL。
  文件检查内容独立于当前轮次 JSON 记录导出；记录中的“文件未读取/验收”仅描述该导出范围。

接口使用 `abr.file-snapshots.v1`：Gateway POST `/api/v1/agent/gateway/file-snapshots`；
用户 GET `/api/v1/agent/sessions/{session}/turns/{turn}/file-snapshots` 及末尾 `/{snapshot_id}`。
浏览器使用同构的 `/web/api/...` Cookie facade；仅接受不透明 ID，不接受路径、URL、Range 或请求正文。
摘要只标记 `content_integrity_only`；目标验收和生产 SSO 验收仍独立处理。

### 同一任务的文件版本对比

在结果检查的 **文件版本对比** 中点击 **选择对比轮次**，选择另一已结束轮次作基准，再点击
对应路径的 **比较内容**。方向始终为「基准 → 当前查看轮次」，不会改变正在编辑的任务草稿。
历史每页 20 条、每次搜索最多 32 页候选，只保留有界轮次元数据；可以返回上一页。
用 **搜索基准轮次** 按可见指令或 ID、状态定位更早的基准，搜索不局限于最新 640 轮，
但仍受上述服务端扫描预算限制。基准可早于或晚于当前查看轮次，必须属于同一任务、同一实例。

- 复用原有只读快照接口与权限，没有新的工作区读取、执行、合并或发布入口。
  对应关系按完整路径精确匹配；只有双侧可读取快照才允许比较。空文件是 0 字节，
  缺失、未共享或采集不可用不能转成空文件，也不能据此认定文件新增、删除或重命名。
- 每次比较及 **下载差异记录** 均重新读取双方不透明文件 ID、核对绑定与 SHA-256，并在操作
  前后复核登录上下文。实例撤权即使不改变 `/access` scopes，也会由文件端点拒绝。
  一侧失败会取消另一侧尚未完成的请求；两个文件面板观察到撤权时共同清除内容。
- 文本按原始 UTF-8 比较，保留 BOM、CRLF/LF/CR 和末尾换行差异。显示行号、增加/移除标记和
  默认前后 3 行上下文，可展开全部有界上下文。格式控制字符及反斜杠转义显示，不解释 HTML。
  二进制只给出摘要与字节状态，不伪造文本行差异。
- 每侧最多 64KiB、2000 行；对齐最多 200 万工作步和 200 万 Int32 trace 单元，输出最多
  4000 行。超过预算明确显示逐行比较未完成，增加/移除数量为未知，不显示部分结果冒充完整差异。
- JSON 导出使用 `abr.file-comparison.v1`，包含双方轮次/快照 ID、Hub 接收时间、路径、摘要、
  比较状态和有界原文行及其行尾。`changed` 记录可重建双侧文本；相同、二进制或超限记录仅含
  相应状态与元数据。它不是可直接应用的补丁，不代表文件归因或目标验收。

## 配置与权限：两个独立条件

默认 `web.control: false`（省略也为 false），原只读配置和租户只读策略保持兼容。
新前端提供操作入口，但不能由浏览器勾选权限或自行注册身份。

完整占位模板：[agent-hub-web-control.yaml](../../examples/agent-hub-web-control.yaml)。
须先在 Snaplink 经批准允许专用 public/S256 Web client 请求以下 scopes/resource，
再由操作员配置本人**真实 client-specific subject**、tenant/client及精确实例：

```yaml
web:
  public_origin: https://abr.ywbsd.site
  client_id: REPLACE_APPROVED_WEB_CLIENT
  tenant_id: REPLACE_TENANT
  control: true
auth:
  # 仍需 jwt / issuer / jwks_url / audience / algorithms，见完整模板
  grants:
    - tenant_id: REPLACE_TENANT
      subject: REPLACE_CONFIRMED_WEB_PAIRWISE_SUBJECT
      client_id: REPLACE_APPROVED_WEB_CLIENT
      kind: user
      instances: [abr-local]
      scopes: [agent.instances:read, agent.sessions:read, agent.sessions:write, agent.turns:cancel]
```

- `control: true` 仅开启 facade 和 SDK 申请写 scopes，**不授予任何权限**。
  grant 与签名 access token 的 scope 必须同时允许操作；写入与取消分别授权。
- 新任务详情、事件和操作记录也要求**精确 principal grant**，不启用 tenant-wide metadata fallback。
  `web_read_grants` 即使收到带写 scope 的 token，也只能继续读取实例/会话元数据。
- 每次请求仍验签及核对 issuer/audience/tenant/client/subject、实例范围、可选 membership gate；
  POST 读取正文后再次验证浏览器会话，上传期间退出或撤权不会借用旧 principal。
- 原 `/api/v1/agent/*` 仍仅接受 Bearer，Cookie 不成为原 API 的凭据，Web 不接受混合 Authorization。
- ID token、邮箱、Console subject、首位访客、已有租户策略都不能替代本人授权批准。
  Web public client 不需要 secret；不重复注册或自动扩大既有客户端授权。

## 执行型 Gateway

需要独立批准的机器身份和执行型 Gateway。`--observe-only` 不执行，不能原地把其状态目录
改成执行模式；也不能通过删除观察绑定绕过检查。停止并核对原所有者后，用独立执行态接入：

```sh
abr fleet serve --config /private/agent-hub-web-control.yaml \
  --host 127.0.0.1 --port 8788 --check-config --json

# 仅为配置示例，路径、身份和项目必须先经授权；不要原样运行占位值。
abr fleet agent --hub https://abr.ywbsd.site \
  --oauth-config /private/approved-gateway-oauth.json \
  --cwd /path/to/approved-project --state-dir /private/abr-executor-state \
  --instance-id abr-local --project-id abr --agent pi --sessions 0 --max-sessions 2
```

`--sessions 0` 表示等待按需创建，不是观察模式；provider、预算和工程门禁仍来自 Gateway/
AgentSession 的既有配置。先读目标项目 AGENTS.md；这个入口不自动为共享仓库提供 worktree 隔离。
需要分享命令终态输出时，在已批准的执行网关命令中显式添加 `--publish-command-output`。
此选项扩大向Hub发布的会话内容，默认关闭；观察模式拒绝该选项，已有服务配置不会自动更改。
初次接入应只创建所需会话，避免多个 Agent 同时写同一工作区。旧进程/会话不自动导入。
`--check-config` 只核对本地配置，不能证明 client、真实用户、机器授权或执行环境已可用。

长回复产生事件积压时，执行型 Gateway 会连续发送已成功推进的批次，减少输出和完成状态
到达页面前的额外等待。网络失败、确认无效或启动结果未决时仍按原间隔重试；不会重放指令。
批次之间继续检查取消命令，页面仍以 Gateway 确认的终态判断是否停止，不能把取消请求
已提交当作执行已结束。

## 浏览器传输与不确定结果

仅白名单提供同源适配，不接受任意 URL 或工具调用：

| 路由（`/web/api` 下） | 方法 |
|---|---|
| `/access` | GET：非授权凭据的能力/登录上下文投影 |
| `/task-sessions` | GET；精确授权任务目录，`after`分页，`instance_id`、`state`、`q`筛选 |
| `/sessions/{id}`、`/sessions/{id}/events`、`/turns/{id}` | GET；events 可用 `turn_id` 限定同会话轮次 |
| `/sessions/{id}/turns` | GET；最新优先，`q`/`state` 搜索与 `before` 分页，每页最多20条；互斥 `turn_id` 精确读取最多1条 |
| `/session-operations`、`/session-requests/{id}`、`/session-close-requests/{id}` | GET |
| `/instances/{id}/sessions` | POST 创建；仅 `name` |
| `/sessions/{id}/turns` | POST 指令；仅 `prompt` |
| `/turns/{id}/cancel`、`/sessions/{id}/close` | POST；空 JSON 对象 |

POST 必须具有精确 Host/Origin、单个 JSON Content-Type/Content-Length、
`Idempotency-Key` 和与当前 Cookie 登录匹配的 `X-ABR-Context`。上下文是随机会话 key 的
SHA256，仅防止延迟写入借用另一账号的 Cookie，不是令牌或授权能力。重复头、跨源/null Origin、
Transfer-Encoding、压缩正文、重复 JSON 键、无效 UTF-8、未知字段、坏路径均拒绝。
JSON正文最多64KiB，完整正文读取最多5秒；持续流量不延长。名称最多256 UTF-8字节，prompt最多16KiB。

前端一次读/写窗口12秒、响应2MiB/1024块；实例/概况列表每类100条、任务目录每页20条、
请求记录/轮次20条、事件每页50条。任务目录接口最多50条，查询最多128字符/512 UTF-8字节，
未知字段、无效UTF-8、GET正文、越权实例和无效游标均拒绝；数据库查询预算耗尽明确失败。
任务页可见时执行非重叠的只读同步，默认间隔2秒；网络失败有界退避，连续3次失败停止，
鉴权/格式/限流等拒绝立即停止，手动刷新可重新核对。隐藏页面暂停只读轮询，不中止已发出的写请求。
一次最多推进3页事件，浏览器保留最多500条/1MiB事件正文，消息显示共享256KiB预算并标记截断。
草稿最多16个会话、每份64KiB，实际发送仍受16KiB限制。无浏览器token存储，无自动重试写入。
动作只保留一份内存中的冻结目标、正文、context和随机key。
网络失败、5xx、超时或坏成功响应都显示**结果未知**，阻断新写入；读取不代表撤销请求。
可先只读查询，再显式用原目标、正文和key核对重试；换账号或失去权限不能重放。
离开页面丢失本地确认信息，页面会提示；Hub请求账本仍保留。当前页没有记录不证明未受理。

## 验证与未完成的部署验收

`tests/test_hub_web_control*.py` 覆盖真实本地 HTTP/SQLite/SDK/JWT，以及 scopes、实例、租户
只读降权、CSRF、重复头、正文预算、退出竞态和幂等。`web/tests/tasks.test.ts` 覆盖提交锁、
未知结果、原key重试、账号切换、deadline、游标和生命周期。
`tests/browser_hub_web_control.py` 经真实 Chrome、TLS、Hub、Gateway、AgentSession 验证桌面/
手机创建、多轮成功、失败后继续、取消/关闭、自动输出、分块去重、历史/导航/草稿及未知提交核对，
**仅 issuer 和 provider 是确定性测试替身**；不调用真实模型或生产项目。
`tests/browser_hub_web_results.py` 追加结果页、记录下载、格式/代码复制、跨轮次隔离、撤权与键盘页签验证。
同时覆盖命令输出默认私有、显式共享、脱敏、复制/导出、空值/截断，以及桌面和手机上的操作。
`tests/browser_hub_web_catalog.py` 验证失败任务找回并继续执行、超过100条会话的搜索/分页、
桌面/手机保留草稿、字面量及Unicode查询、撤权和账号切换。目录大样本为真实Hub账本记录，
不等于同时运行相同数量的Agent；执行闭环仍通过实际Gateway/AgentSession测试。
`tests/browser_hub_web_diff.py` 验证桌面/手机的真实快照对比、原文行重建、历史基准分页、
二进制/空/缺失区分、双侧摘要篡改、实例撤权、跨面板清理、迟到响应和超限记录。
`tests/browser_hub_web_history.py` 验证历史搜索/分页、可见脱敏语义、精确轮次链接、刷新与前进后退、
草稿隔离、跨会话拒绝、较早快照基准定位，以及主读取忙时切换轮次阻断迟到导出的真实浏览器竞态。
`tests/browser_hub_web_review.py` 覆盖桌面/手机在第 64 条之后定位问题、结果分页与状态筛选、
证据引用、编辑和保留最新原稿、预算拒绝、双击去重、撤权/轮次切换清理及显式发送后只执行一次。
测试中的命令记录由确定性 provider 发出，不代表实际运行了同数量的系统命令。
`tests/browser_hub_web_drafts.py` 覆盖桌面/手机的文本备份、刷新后手动恢复、预览期间修改原稿、
明确发送、容量与编码拒绝，以及撤权/导航/未知提交时的文件读取和草稿边界。
`tests/browser_hub_web_drain.py` 使用 Gateway 正式主循环和默认命令轮询间隔，验证多批长回复
完整到达、精确轮次终态、手机取消及显式下一轮。固定等待、失败重试和停机竞态另由
`tests/test_hub_gateway_drain.py` 的受控时钟测试核对；浏览器测试不承诺网络或真实模型延迟。
上述浏览器测试由 `make web-browser` 及既有CI/发行Web门禁调用，不属于默认pytest收集。

代码通过不等于已部署。公网本人身份、当前实际 Web client、精确 grant、机器凭据、
服务整体切换与存储恢复仍须独立批准/验收；沿用已确认 HTTP/customDomains 路由。
此前只读候选的全量CI/镜像扫描不覆盖这次控制增量，不能直接拿旧镜像部署新功能。
