# 后端设计智能 06：产品工程流水线（Product Engineering Pipeline）

> 完整生命周期：先考察再立项 → 体验原型 → 技术推演 → 可维护模型 →
> 系统设计 → 代码 → 监控 → 持续优化。不是"代码驱动产品"，而是
> **人驱动产品 → 体验驱动设计 → 业务驱动模型 → 模型驱动代码**。

## 1. 完整思维链

```
人 → 用户心理 → 产品目标 → UX 体验 → UI 视觉 → 交互流程
  → 业务流程 → 领域模型 → 数据库 → API → 服务架构
  → 代码 → 监控 → 持续优化
```

## 2. 立项顺序（先考察再立项）

| 阶段 | 产出 | 禁止 |
|---|---|---|
| 0. 业务场景建模 | 场景/问题/目标/约束（4 小时排产 → 30 分钟） | 直接建表 |
| 1. 用户研究 | 角色 × 关注点 × 入口（老板驾驶舱/PMC 工作台/执行台） | 一个首页 |
| 2. 任务分析（JTBD） | "知道今天哪些订单延期并调整"（非"查看订单"） | 功能列表 |
| 3. 体验原型 | 用户流程 → 低保真 → 高保真 → 用户测试（页面暴露模型缺口） | 先做数据库 |
| 4. 技术推演 | 规模/并发/生命周期预测 → 单体/微服务/异步/事件 | 默认微服务 |
| 5. 可维护模型 | 领域模型 + 状态机 + 数据模型（含审计/历史） | 直接写代码 |
| 6. 系统设计 | 服务拆分/API/DB/缓存/消息/安全/部署 | 凭空设计 |
| 7. 代码 | 契约 → 前后端 → 测试 → 部署 | — |
| 8. 监控优化 | 埋点 → 行为分析 → 迭代（运营智能） | 上线即结束 |

## 3. 循环验证（非线性）

```
提出假设 → 用户价值验证 → 体验设计 → 技术可行性验证 → 调整 → 落地
```

技术约束（成本/延迟/合规）随时反向修正体验设计——不是瀑布，是回路。

## 4. 预判未来变化（3 年视角）

- 现在 100 家 → 未来 10000 家：租户/权限显式建模
- 单机 → 分布式：事件/幂等/一致性边界先正确
- 克制：不为假设的规模提前造抽象（三次原则），但**边界**（租户/审计/幂等）先正确

## 5. Agent 流水线映射

```
Phase 0  业务探索 Agent（场景/问题/目标/约束）
Phase 1  用户研究 Agent（角色/关注/入口）
Phase 2  产品经理 Agent（JTBD/优先级/验收）
Phase 3  UX/UI Designer Agent（流程/原型/信息优先级/色彩智能）
Phase 4  技术架构 Agent（规模/并发/体验预算）
Phase 5  Domain Modeling Agent（领域模型/状态机/数据模型）
Phase 6  Frontend Agent（组件/动效/门禁）
Phase 7  Backend Agent（领域/API/持久化/门禁）
Phase 8  QA + Security Agent（五层测试/安全基线）
Phase 9  Product Review Agent（Attention Score/体验回测/假设验证）
```

## 6. 检查清单

```
□ 是否先考察（场景/用户/任务）再立项？
□ 体验原型是否先于数据库？
□ 技术推演是否覆盖规模/并发/生命周期？
□ 是否循环验证（技术约束反向修正设计）？
□ 是否预判 3 年变化（边界先正确，抽象克制）？
□ 上线是否带埋点与假设回测？
```
