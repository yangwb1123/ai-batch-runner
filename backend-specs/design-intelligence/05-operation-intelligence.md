# 后端设计智能 05：运营智能（Operation Intelligence）

> 上线不是终点：用户是否喜欢？哪一步卡住？哪里流失？
> 设计 → 埋点 → 行为分析 → 优化 → 迭代，闭环验证设计假设。

## 1. 埋点先于上线

每个关键交互埋点：

- 页面打开（停留/退出）
- 操作（点击/提交/失败/重试）
- 流程（漏斗各步）
- 功能（使用率）

**规则**：核心页面与流程在设计阶段就确定埋点方案，随功能一起上线。

## 2. 行为分析驱动迭代

示例：发现"订单页面 80% 点击在异常区" → 异常应该放首页（信息优先级验证）。

- 漏斗分析：哪一步流失最多？
- 功能使用率：哪些功能没人用（考虑隐藏/下架）？
- 错误率：哪些操作频繁失败（修复优先级）？
- 时长：哪些页面停留过长（可用性问题）？

## 3. A/B 与实验

- 关键改动（布局/流程/文案）A/B 验证
- 指标先行（转化率/完成率/时长）

## 4. 运营与设计闭环

```
设计假设 → 上线 → 埋点 → 数据分析 → 验证/推翻假设 → 下一轮设计
```

**规则**：设计文档记录假设（"异常置顶可减少处理时间"），上线后回测。

## 5. 检查清单

```
□ 核心交互是否埋点？
□ 关键流程是否有漏斗？
□ 功能使用率是否可观测？
□ 错误率是否监控？
□ 设计假设是否记录并可回测？
□ 是否有 A/B 机制（关键改动）？
```
