# Profile: 营销官网与落地页（业务风格配置）

流水线 classify 阶段输出 `product_type: marketing` 时，生成与审查 Agent 采用
本 profile（叠加在通用 spacing/component/layout 规范之上）。

## 目标

吸引注意、解释价值、推动转化。

## 视觉

大留白、强视觉层级、大标题、品牌色、单页围绕一个转化目标。

## 布局

首屏价值主张 → 核心卖点 → 产品展示 → 使用场景 → 客户证明 → 价格/方案 → FAQ → 转化行动。

## 交互

首屏明确 CTA、CTA 描述结果、表单字段尽量少、滚动中重复提供 CTA、动画不阻碍阅读、移动端首屏重点清晰、提交后说明下一步。

## 禁止

一屏多个同等级目标、动画多于内容、首屏不知产品做什么、所有文字居中、提交后无反馈。
