# Profile: CMS 内容管理（业务风格配置）

流水线 classify 阶段输出 `product_type: cms` 时，生成与审查 Agent 采用
本 profile（叠加在通用 spacing/component/layout 规范之上）。

## 目标

编辑人员快速完成内容创建、修改、审核、发布与版本管理。

## 视觉

中等密度、内容分区清晰、状态标签明显、草稿/审核/发布状态强调。

## 布局

应用导航 → 标题+状态 → 筛选工具栏 → 内容列表 → 批量操作 → 分页；编辑器=顶部操作栏+主编辑区+右侧设置区。

## 交互

自动保存草稿、离开前检查未保存、提交前校验必填、发布前预览、版本比较恢复、删除进回收站、批量操作显示影响数量。

## 禁止

保存/提交/发布混为一个按钮、无草稿状态、离开不提示未保存、发布无二次确认、版本覆盖不可恢复。
