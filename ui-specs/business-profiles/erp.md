# Profile: ERP / MES / 生产管理系统（业务风格配置）

流水线 classify 阶段输出 `product_type: erp` 时，生成与审查 Agent 采用
本 profile（叠加在通用 spacing/component/layout 规范之上）。

## 目标

业务人员高效率、低错误地处理大量结构化数据和单据。
**优先：业务正确性 > 操作效率 > 状态可见 > 防错 > 密度 > 一致性。**

## 视觉

- 高信息密度，桌面端优先，表格为核心
- 间距紧凑但不拥挤：pageGap 24 / sectionGap 24 / cardPadding 16-20 /
  tableRow 40-48（紧凑档）
- 状态颜色明确、只用文字+颜色双表达；动画极少（motion_level 0）
- 只允许：加载、展开收起、状态切换、焦点提示

## 布局

- 左侧导航；内容宽度 fluid
- 详情用抽屉或分屏（保留列表上下文），复杂编辑才用独立页面
- 页面骨架：标题+状态 → 快捷操作 → 查询条件 → 统计摘要 → 数据表格 →
  明细面板 → 分页与汇总

## 表格

- 固定表头、关键列固定、列宽可调、密度切换
- 数字右对齐、文本左对齐、状态居中、金额千分位、日期格式统一
- 批量选择后显示批量操作栏（影响数量 + 确认）

## 交互

- 高频操作不离开当前页；单元格编辑显示编辑状态
- 保存失败不得丢失已编辑内容；高风险操作二次确认
- 单据提交后进入明确状态流转：草稿 → 已提交 → 审核中 → 已审核 →
  已执行 → 已完成（驳回→草稿、撤回→草稿、作废申请→已作废）

## 禁止

- 营销官网式大留白；表格行过高；所有操作跳新页；状态只有颜色没文字；
  用户改数据后无变更提示；保存失败清空表单
