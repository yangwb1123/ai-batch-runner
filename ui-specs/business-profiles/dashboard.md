# Profile: 数据分析后台（业务风格配置）

流水线 classify 阶段输出 `product_type: dashboard` 时，生成与审查 Agent 采用
本 profile（叠加在通用 spacing/component/layout 规范之上）。

## 目标

帮助用户理解数据、发现问题并做出决策。

## 视觉

数字优先、图表服务于问题、对比关系明确、筛选范围清晰。

## 布局

标题+更新时间 → 全局筛选 → 核心指标 → 趋势 → 结构 → 异常 → 明细。

## 交互

筛选变化说明影响范围、图表可下钻可返回、Tooltip 完整值+时间+单位、图表与表格同口径、导出携带筛选条件、空数据与错误区分。

## 禁止

一屏十几种图表、图表无单位、颜色无业务含义、图表与表格口径不同。
