# Geometry Spec — UI 几何构图规范（AI UI 生成必备资产）

> 目的：让 Agent 生成页面时**先构图、后写码**——先建立隐形对齐轴、比例家族、
> 间距节奏、视觉重心，再编译成代码。违反本规范的写法由 `uigeometry`
> 验证器机械拦截，且任意像素值/无解释偏移在评审中必须给出理由。

## 1. 生成前必答（几何契约）

写任何 TSX / Dart / Vue 前，先在心里（或输出注释块）建立：

1. 页面区域划分（标题区/操作区/筛选区/内容区/辅助区）
2. 主对齐轴（左边缘/右边缘/中轴/文字基线/数字右对齐线）
3. 间距节奏（元素属于哪个关系层：微组件 4-8 / 强关联 8-12 / 同组 16 /
   子模块 24 / 独立模块 32-40 / 大区域 48-64）
4. 线条策略（留白 > 背景差异 > 阴影 > 分隔线 > 完整边框）
5. 比例与形状家族（圆角/控件高度来自 token）
6. 光学修正清单（1-2px 视觉微调必须显式声明，禁止裸数值）

## 2. 对齐规则

- 每个可见元素必须属于一个视觉分组；每个分组声明主对齐轴。
- **优先复用已有轴**，一个区块最多 3 条主导纵向轴。
- 页面标题、筛选区、内容区、表格必须共享 content-left / content-right；
  禁止出现标题 24px、筛选 32px、表格 20px 的"页面抖动"。
- 数字列右对齐；文本列左对齐；状态列统一轴；日期固定格式。
- 相邻分组间距来自关系层，不允许"看起来挤就加一点"。

## 3. 线条规则

- 线的五种语义：边界 / 分隔 / 引导 / 关系 / 强调——每条线必须能回答
  "表达什么"。
- 能用留白表达分组时**不画线**；能靠背景层级表达区域时**不加完整边框**。
- 分隔线端点必须对齐：容器级→容器边缘；内容级→文字起始轴；
  列表分隔线缩进到文字起始线。
- 线条宽度收敛为有限层级：`--stroke-hairline:1px`（边界/弱分隔）、
  `--stroke-active:2px`（激活/焦点）、`--stroke-emphasis:3px`（强状态）。
  禁止 1.2px/1.5px 等随机宽度。

## 4. 比例与形状家族

- 间距必须来自 spacing.md 的 token 集（8pt 体系，允许 20 为卡片 padding）。
- 圆角家族：`radius.sm 6 / md 10 / lg 16`；控件高度家族：
  `control.sm 32 / md 40 / lg 48`。
- 禁止 13px/17px/19px/21px/27px 等游离值——除非是**已记录的光学修正**。
- 相似语义组件共享形状语言：图标容器、按钮、标签、卡片圆角体系一致。

## 5. 视觉平衡与光学修正

- 视觉重量 = 面积 × 对比 × 密度 × 强调 × 复杂度；两栏 50% 不等于平衡。
- 数学居中 ≠ 视觉居中：图标留白、三角形重心、中英文基线差异需 1-2px
  光学修正。
- 光学修正必须显式声明并集中管理：

  ```css
  .icon { transform: translateY(var(--optical-offset-y, 0)); }
  :root { --optical-offset-y: -1px; /* 图标视觉中心下移 */ }
  ```

- 禁止散落的 `margin-top: 3px; left: -2px;` 等无法解释的偏移。

## 6. 反模式（uigeometry 验证器拦截）

- 裸数字小偏移（1-3px 的 margin/transform，未绑定 --optical 变量）
- 随机圆角（非 6/10/16）
- 随机线条宽度（非 1/2/3）
- 无意义的绝对定位（非弹层/遮罩/徽标场景）
- 同一区块内混用多套对齐体系（左右混排无层级）
- 所有区域都套 Card + 边框（应有留白/背景差异优先）

## 7. 验收

- 渲染后用 DOM 测量验证主轴偏差 ≤ 1.5px（标题/筛选/表格同轴）。
- 视觉重心稳定、阅读动线明确、无意外粘连。
- 几何评分 < 80 必须重新布局；80-89 自动修正复检；≥90 才可人工验收。
