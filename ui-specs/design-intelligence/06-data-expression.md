# 设计智能规范 06：数据表达与视觉故事（Data Expression）

> 数据不是字段罗列，是表达。选择正确的表达方式 = 用户 3 秒理解。

## 1. 数据表达选择表

| 数据意图 | 表达 | 示例 |
|---|---|---|
| 单个关键值 | 大数字 + 趋势 | 98% ↑5.2% |
| 进度/健康度 | 进度条 + 百分比 + 建议 | ████████░░ 82% 安全 |
| 趋势 | 折线图（Sparkline） | 30 点迷你趋势 |
| 分布 | 条形/占比条 | Top 租户用量条 |
| 对比 | 条形图/分组 | 各域计数 |
| 状态集合 | 色编码徽章组 | 🟢 230 / 🟡 8 / 🔴 12 |
| 时间序列事件 | 时间线 | 登录历史圆点连线 |
| 关联 | 关系图/引用链 | 审批流 |

**规则**：能用图形表达的不裸文字；图表数据必须来自语义色。

## 2. 数据故事化

数字 + 一句人话：

- ❌ `库存: 10000`
- ✅ `库存健康度 82% · 安全 · 预计可支持 35 天生产`

## 3. 建议性表达（决策支持）

用户要的不是数字，是**决策**：

- `建议: 无需采购`（比"库存 500"少认知成本）
- `风险: 3 个订单可能延期`（比"状态: 进行中"更有行动指向）

## 4. 图表规范

- 语义色：正常绿/警告黄/异常红/信息蓝（禁止随机色）
- 动效：绘制动画（500ms 生长）+ 末端圆点
- 高密度：多数据点用 sparkline/迷你图，不进大图
- 坐标轴：非必要时隐藏（大屏/工作台场景）

## 5. 数据密度层次（Bloomberg 模式）

```
一级：大数字（KPI）
二级：图表（趋势/分布）
三级：表格（可排序/搜索）
四级：详情（折叠/钻取）
```

## 6. 检查清单

```
□ 关键值是否大数字 + 趋势 + 上下文
□ 健康度/进度是否图形化 + 建议
□ 状态是否色编码徽章（双编码）
□ 图表是否语义色
□ 是否给决策建议（而非裸数据）
□ 密度层次是否清晰
```
