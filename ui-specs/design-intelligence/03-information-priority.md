# 设计智能规范 03：信息优先级（Information Priority Intelligence）

> 页面不是展示所有数据，而是引导用户看到最重要的数据并产生下一步行为。
> "数据库展示"不是产品界面。

## 1. 页面首先确定视觉焦点

用户进入页面 **3 秒内**应该看到什么？

- ❌ 平铺：订单列表 / 设备列表 / 人员列表 / 库存列表
- ✅ 焦点：今日生产达成率 98% ↑5% + 异常订单 3（立即处理→）

视觉顺序：**核心指标 → 异常 → 趋势 → 详细数据**

## 2. 数据价值决定显示面积

不是所有 Card 一样大小。重要数据占大空间、高对比、可动效；普通数据降权。

```
┌──────────────────────────────┐
│        核心指标 98%（大）     │
├────────────┬─────────────────┤
│ 异常 3     │ 趋势图          │
├────────────┴─────────────────┤
│ 详细列表                      │
└──────────────────────────────┘
```

重要占 ~80% 视觉空间，普通 ~20%。

## 3. KPI 大数字设计

❌ `完成率: 98%`

✅
```
        98%          ← 大数字（headline，粗体，字距收紧）
    生产完成率        ← 小标签
    ↑ 5.2%           ← 趋势箭头 + 环比
  超过历史平均        ← 一句上下文
```

- 大数字：≥ 28px、粗体、颜色强调（正常=语义色/品牌色）
- 趋势：箭头 + 百分比 + 色编码（升绿/降红或按业务语义）
- 上下文：一句话让用户理解含义

## 4. 数据故事化（Data Storytelling）

不是显示数据，是讲故事：

- ❌ `库存: 10000`
- ✅ `库存健康度 ████████░░ 82% 安全 · 预计可支持 35 天生产`

用户**马上理解**，不需要读表。

## 5. 异常优先原则（Exception First）

管理者关心"哪里有问题"：

- ❌ 展示全部，用户自己找
- ✅ 异常置顶 + 色编码 + 处理入口（🟢 正常 98% / 🔴 异常 3 / ⚠ 即将延期 5）

## 6. 动态突出显示

数据变化时 UI 应调整：

- 正常：常规展示
- 突破：放大 + 动效 + 高亮 + 排序提升（🔥 销售额 500万 ↑300%）

## 7. Attention Design（注意力设计）

**一个页面最多 3 个视觉焦点**（Apple Watch 原则：只显示最重要的一件事）。

超过 3 个 → 全部重点 = 没有重点 → 降级为普通数据或折叠。

## 8. 布局随业务生成（非固定模板）

不是 Row/Card 循环，而是按角色生成布局：

- **CEO**：收入 / 利润 + 用户 / 趋势 / 风险
- **工程师**：CPU/内存/网络 + 实时日志 + 错误追踪
- **生产主管**：今日产量 + 设备状态 + 异常订单

## 9. 视觉吸引力（第一眼冲击）

- **Hero Metric**：最大的数字 + 背景视觉（渐变/粒子/Glow/Glass/Motion）
- **进入动效**：数字增长动画、图表绘制动画、卡片浮现
- **禁止**：动画污染效率（操作路径上的动画 ≤ 300ms，循环动画仅装饰区）

## 10. 信息密度控制（高密度 + 高理解）

Bloomberg 模式：数据多但层次清晰。

```
一级：大数字
二级：图表
三级：表格
四级：详情（折叠）
```

## 11. Visual Attention Score（页面生成评分）

| 维度 | 权重 |
|---|---|
| 视觉焦点 | 20 |
| 信息层级 | 20 |
| 重点突出 | 20 |
| 数据表达 | 15 |
| 布局合理 | 10 |
| 美观程度 | 10 |
| 创新性 | 5 |

**低于 80 分重新设计**。

## 11.5 导航架构规则（两级 IA，实战验证）

- **一级导航 ≤8 项**（参考 Supabase 8/Stripe 6/Vercel 7）；超过即需要分组
- **两级结构**：一级 NavigationRail 只放组；组内模块用页面内 tabs
  （SectionSelector）；≤2 次点击到达任何模块
- 路由零破坏：模块 id 保留，组是**纯导航层派生**（不进入路由状态）
- 组内模块记忆（切组回来记住上次位置）
- 能力裁剪：组内无可见模块时整组隐藏
- 深链直达自动高亮所在组

## 12. Information Architecture Rules（Agent 系统规则）

**页面不是数据容器，页面必须主动引导用户注意。**

生成 UI 前分析：
1. 最重要指标是什么？
2. 用户进入页面第一眼看到什么？
3. 哪些数据需要突出？
4. 哪些数据应该隐藏？
5. 哪些数据应该图形化？
6. 哪些异常需要主动提醒？

设计原则：
- 重要数据：更大空间、更高对比、动态效果、颜色强调
- 普通数据：降低视觉权重
- **禁止所有内容同等展示**

目标：**让用户 3 秒理解页面价值**。
