# Defect Patterns — 缺陷模式库（经验事故档案）

"十年经验"最有价值的不是推荐写法，而是**在什么条件下发生什么事故**。
每个模式：触发条件 → 表面现象 → 根因 → 检测方法 → 测试方法。

## 1. async-race（请求竞态）

- **触发**：用户快速切换筛选/搜索词，旧请求晚于新请求返回
- **现象**：页面偶尔显示上一次筛选的结果
- **根因**：响应没有版本控制或取消机制
- **检测**：搜索 watch/useEffect 中的异步请求；检查 AbortController /
  requestId 比对；禁止只靠 loading 布尔
- **测试**：两个 Deferred Promise，控制旧请求晚返回，断言旧响应不生效

## 2. duplicate-submit（重复提交）

- **触发**：双击保存/审批/支付按钮；网络慢时重复点击
- **根因**：只有按钮 disabled（UI 层），无 pending lock / 幂等键
- **检测**：写操作 handler 是否防重入；请求头是否有 Idempotency-Key；
  超时后是否允许盲目重试
- **测试**：快速双击，断言请求只发出一次

## 3. stale-closure（过期闭包）

- **触发**：setTimeout/事件回调捕获旧 state
- **检测**：异步回调中的 state 引用是否来自渲染时快照；依赖数组是否完整
- **测试**：延迟回调 + 期间更新状态，断言回调使用最新值

## 4. effect-loop（副作用循环）

- **触发**：effect 内部更新其依赖的状态 → 无限循环
- **检测**：effect 依赖中是否有 effect 内 setState 的变量；日志重复输出
- **测试**：限制渲染次数断言

## 5. event-listener-leak（监听泄漏）

- **触发**：组件卸载后 window/document 监听未移除；定时器未清理
- **检测**：addEventListener/on + 无 removeEventListener；setInterval
  无 clearInterval；订阅无取消
- **测试**：挂载/卸载多次，断言监听数不增长

## 6. permission-ui-only（仅 UI 权限）

- **触发**：隐藏按钮但未做服务端校验；`role === 'admin'` 散落判断
- **检测**：搜索角色字符串判断；检查写操作是否只有前端拦截
- **测试**：直接调用 API 断言服务端拒绝

## 7. pagination-filter-mismatch（分页筛选错位）

- **触发**：切换筛选后停留在第 5 页；删除末页最后一条后空页
- **检测**：筛选变更是否重置页码；页码是否随数据变化回退
- **测试**：筛选 → 断言回到第 1 页；删末页最后一条 → 断言页码回退

## 8. optimistic-update-rollback（乐观更新无法回滚）

- **触发**：乐观更新成功显示后请求失败，界面停留在错误状态
- **检测**：乐观更新是否保存快照；失败路径是否恢复原值
- **测试**：mock 失败，断言 UI 回滚且错误可见

## 9. form-dirty-state-loss（脏数据丢失）

- **触发**：路由离开/弹窗关闭/刷新，未提示未保存
- **检测**：表单是否有 dirty 跟踪；beforeunload/路由守卫是否拦截
- **测试**：编辑后离开，断言有提示；确认放弃才丢数据

## 10. derived-state-divergence（派生状态漂移）

- **触发**：同一数据被复制到多个本地 state，一处更新他处过期
- **检测**：搜索 setState 是否赋值为另一 state 的派生值；是否应计算
- **测试**：更新源，断言所有展示位置一致

## 11. selection-cross-page（跨页选择丢失）

- **触发**：表格第 1 页选中 → 翻页 → 返回，选择丢失或误操作全量
- **检测**：SelectionMode 是否显式（current-page/explicit/all-matching）
- **测试**：跨页选择后断言选择集合语义正确

## 12. timeout-uncertain（超时不确定）

- **触发**：写请求超时，实际服务端已成功，客户端盲目重试 → 重复执行
- **检测**：写操作超时路径是否有 uncertain 状态/查询操作结果
- **测试**：mock 超时但服务端成功，断言 UI 不重复提交并提示确认

审查时对每个模式回答：**旧请求返回时还能修改状态吗？卸载后还更新吗？
重复点击会重复提交吗？失败后能恢复吗？**
