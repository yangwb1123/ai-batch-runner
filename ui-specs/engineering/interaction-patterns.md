# Interaction Patterns Spec — 交互模式库（决策表）

## 0. 手势竞争清单（实战教训）

可交互容器（行/单元格）内嵌套手势组件时注意 recognizer 竞争：

| 场景 | 问题 | 修复 |
|---|---|---|
| 行 InkWell(长按=批量选择) + Tooltip(默认长按触发) | Tooltip 吞掉长按，批量选择失效 | Tooltip `triggerMode: tap` |
| 行点击(详情) + 单元格点击(复制) | 单元格拦截行点击 | 选择模式/编辑模式禁用单元格手势（enabled 参数） |
| 行长按 + 单元格长按 | 内层长按优先 | 非交互单元格才透传行长按 |

**规则**：行级交互（点击/长按）与单元格级交互必须明确层级；模式切换
（选择/编辑）时低优先级单元格手势自动让位。

## 1. 操作分级（决定视觉等级与确认强度）

| 级别 | 操作 | 视觉 |
|---|---|---|
| 一级 | 页面主任务：新建/保存/提交/发布/审批/购买 | 唯一最高等级 |
| 二级 | 辅助：预览/导出/复制/暂存/筛选 | 次级 |
| 三级 | 低频/危险：删除/作废/转移/重置/关闭流程 | **与主操作不同样式** + 确认 |

一个页面只有一个主任务；危险操作不得与主操作同视觉样式。

## 2. 反馈闭环（每次操作必须完整）

触发 → 系统接收 → 处理中（禁重复点击）→ 返回结果 → 解释结果 → 下一步。

```
❌ 点保存 → 按钮无变化 → 不知道成功没有
✅ 点保存 → loading → 防重复 → 成功提示 → 时间更新 → 提供"继续编辑/返回列表"
```

## 3. 弹窗 / 抽屉 / 独立页面选择

| 场景 | 选择 |
|---|---|
| 简单确认、少量字段、操作后回原页面 | 弹窗 |
| 查看明细、快速编辑、不想丢列表上下文 | 抽屉 |
| 复杂编辑、多步骤、可分享链接、高风险 | 独立页面 |

## 4. 搜索与筛选

简单查询在工具栏；高级查询展开区。已生效条件可见、可单独移除、一键清空；
返回列表保留条件；复杂业务可保存查询方案。

## 5. 批量操作

选择 → 显示已选数量 → 可用批量操作 → 确认 → 进度 → **成功/失败数量 +
失败原因** → 查看失败明细。禁止只提示"批量操作失败"。
选择模式显式区分：当前页 / 显式 ids / 全部匹配（form-table-state.md）。

## 6. 删除操作

| 数据 | 流程 |
|---|---|
| 低风险 | 简单确认 → 回收站 → 可撤销 |
| 高风险 | 说明影响范围 → 输入对象名确认 → 权限验证 → 执行 → 审计日志 |

## 7. 保存操作（语义必须区分，禁止混用）

自动保存 / 保存草稿 / 保存并继续 / 保存并返回 / 提交 / 发布——每个动作
业务含义不同，按钮文案与行为不得混为一个。

## 8. 异步任务（导出/计算/生成报告）

发起 → 返回任务编号 → 页面可继续操作 → 任务状态可见 → 完成通知 →
下载/查看入口。**禁止全屏 loading 遮罩**让用户等待。

## 9. 危险操作确认层级

保存类确认 < 删除类确认 < 高风险确认（输入名称/影响范围 + 审计）。
审批类操作显示影响对象与后果，驳回必须填原因。

## 10. 禁用清单

- 状态只用颜色不用文字；危险操作与主操作同样式
- 批量操作无明细报告；异步任务全屏遮罩
- 保存/提交/发布混为一个按钮；删除无确认；驳回无原因
- 操作后无反馈、无下一步；返回列表丢失筛选条件
